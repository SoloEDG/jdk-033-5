## 修帆车间

报头「修帆」视图把一块破损帆改裁成可试航的新帆：

- **放样/排料**：用缺口外剩余原布拼 3 块裁片，自动校验避开破损缺口、留在布界、互不重叠，并标注每片经纬（经向）方向。
- **加强条分配**：预算 6 条，可分配到 2 条拼缝共 6 个缝段；提供「堆缝尾 / 均匀 / 清空」预设，也可逐段加减。
- **膜结构验算**：二维弹性杆系 + 雅可比预条件共轭梯度求解，两档阵风（16/24 kn，压力随风速平方）下输出帆形变形、各缝段/帆边/布面拉力与利用率；两片共用的缝段是单一构件，经共享节点把拉力传给邻片。
- **力转移现象**：把加强条堆在缝尾可缓解原超限缝段，但未加强的中段与相邻未加强窄边会成为新超限点，可在帆形图与超限位置对照中看到。
- **试航闸门**：只有两档阵风的所有构件都在材料限值内（且加强条不超预算）才判「准予装船试航」，否则「不予装船试航」。
- **换舷对照**：实航速度由航行动力学按阵风风速推算，与试验中的过载位置、峰值拉力和经纬应变一一对应。
